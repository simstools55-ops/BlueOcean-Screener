# Blue Ocean Screener v0.13.0

## v0.13.0 — 新規サイト用キーワード探索モード

既存サイト向けの通常モードを維持したまま、対象サイトを指定せずに新規サイト立ち上げ向けGREENキーワードを探す専用モードを追加しました。

### 新規サイト探索モード
- 対象サイト名・URLは不要。
- Site Collector Evidenceは不要。
- カニバリ判定は実施しない。
- TRY救済は使用しない。
- キーワード読込 → 一次選抜 → 3語/4語候補 → Claude SERP精査までは既存ロジックを利用。
- SERP精査に「新規サイト適性評価」を追加。
- GREENはSERP・新規サイト適性評価の段階で最終確定。

### 新規サイト適性評価
Claudeは各候補について次を0～100で評価します。
- 参入性
- 需要
- SERP空白
- 展開性
- クラスター形成力
- 継続性
- リスク

`新規サイト適性` は、参入性20%、需要15%、SERP空白15%、展開性15%、クラスター形成力20%、継続性10%、リスク逆数5%を目安に評価します。

### GREEN品質ゲート
- Blue Ocean Score >= 80
- 新規サイト適性 >= 80
- クラスター形成力 >= 70
- リスク <= 60

GREEN未満でも、Blue Ocean Score >= 65、新規サイト適性 >= 65、リスク <= 75 の候補はYELLOW、それ以外はBLOCKです。

### 既存モード
既存サイト用の7ステップ、カニバリ判定、TRY救済、aCreator/SIMS Manager連携は変更していません。

## v0.12.6-dev — GREEN 0件時のTRY救済ルート

通常のGREEN品質ゲートは維持したまま、最終GREENが0件の場合だけ、カニバリ確認済みのロングテールを `TRY` として最大5件提示できるようにしました。

- TRYはGREENではなく、利用者判断による実験候補です。
- SERP YELLOW上位候補をカニバリ精査Packageへ救済候補として同梱します。
- 最終GREENが0件の場合のみ、カニバリLOW/MEDIUMかつ非BLOCKの候補をTRY化します。
- カニバリHIGHはTRYにしません。
- TRYには需要規模・SERP競争・データ不足等のリスクを明示します。
- TRYからもaCreator依頼文を生成し、通常のaCreator処理へ進めます。
- aCreator依頼文には「通常GREENではない実験候補」であることと、カニバリ境界を明記します。
