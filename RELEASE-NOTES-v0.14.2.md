# SIMS Blue Ocean Screener v0.14.2

Release type: Development / Operational Test

## Changes

- Major dialog action buttons now react immediately when clicked.
- Busy operations show a rotating spinner and change the button label to processing text.
- Buttons are disabled while work is in progress to prevent duplicate submissions.
- Copy operations show copying state and explicit completion feedback.
- SERP/Cannibal result registration, aCreator actions, workflow transitions and Candidate Pool re-evaluation were aligned.
- DrivePicker already had busy feedback and remains unchanged.

## Operational test focus

Confirm that every frequently used dialog gives visible feedback immediately after clicking an action button, and that a failed operation restores the button state.
