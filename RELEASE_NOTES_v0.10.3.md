# SIMS Blue Ocean Screener v0.10.3

## Claude API experiment removal
- Claude / Anthropic API integration removed.
- API-key UI and User Properties credential storage removed.
- Metered automatic SERP review removed.
- API-specific model, batch-size, and Web Search settings removed.
- Obsolete API credentials/settings are deleted during initialization.
- External-request OAuth scope removed.
- Supported workflow: Package generation → manual Claude review → response paste.

No change to SERP/cannibal result contracts or Creator/SBM handoff contracts.
